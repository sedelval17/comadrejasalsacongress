# Logo reconstruido

`comadreja-salsa-congress-2026-fondo-negro.png`: **2170 × 725 px**, PNG sobre negro, reconstruido con la herramienta integrada `image_gen` a partir de la referencia pequeña del usuario y la marca más grande recuperada del afiche oficial.

Se conservaron la composición en dos líneas, el serif fino, los colores blanco/dorado y los números decorativos. Es una reconstrucción visual; no se identificó ni se certifica el archivo de la fuente tipográfica exacta.

El prompt final está en `PROMPT_FONDO_NEGRO.txt`. El original del evento y la extracción del afiche permanecen intactos en `public/assets/original/` y `public/assets/brand/wordmark-from-official-poster.webp`.

La copia para la web, `public/assets/brand/comadreja-logo-reconstruido-v1.webp`, está optimizada a 1080 px de ancho. La web usa mezcla CSS `lighten` para integrar el negro con los fondos oscuros sin alterar el archivo original.

Se intentó preparar una variante PNG transparente con `image_gen`; las salidas introdujeron artefactos y se descartaron. **No se entrega una variante transparente como final ni se presenta el PNG como vector.** La versión limpia sobre negro es el resultado seleccionado.
